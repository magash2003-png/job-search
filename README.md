# Job Search Backend

REST API сервиса поиска работы, написанный на Go. Проект поддерживает регистрацию пользователей, авторизацию, работу с вакансиями, резюме, откликами и избранным с разграничением доступа по ролям.

---

## Возможности

### Авторизация

- Регистрация пользователей
- Авторизация пользователей (JWT)

### Роли пользователей

- admin
- employer
- applicant

### Вакансии

- Создание вакансии
- Получение списка вакансий
- Получение вакансии по ID
- Редактирование вакансии
- Удаление вакансии

### Резюме

- Создание резюме
- Получение списка резюме
- Редактирование резюме
- Удаление резюме

### Отклики

- Создание отклика
- Получение своих откликов
- Работодатель видит отклики только на свои вакансии
- Администратор видит все отклики

### Избранное

- Добавление вакансий в избранное
- Получение списка избранного
- Удаление вакансии из избранного

### Дополнительно

- JWT-аутентификация
- Разграничение доступа по ролям
- Проверка существования записей
- Запрет повторных откликов
- Запрет повторного добавления вакансии в избранное
- Красивые JSON-ответы API
- Хранение паролей в виде bcrypt-хеша
- PostgreSQL

## Запуск проекта

### 1. Создайте базу данных PostgreSQL

Создайте базу данных:

```text
job_search
```

### 2. Настройте файл `.env`

Пример:

```env
DB_HOST=localhost
DB_PORT=5432
DB_USER=postgres
DB_PASSWORD=your_password
DB_NAME=job_search

JWT_SECRET=mysecretkey

SERVER_PORT=8080
```

### 3. Установите зависимости

```bash
go mod tidy
```

### 4. Запустите проект

```bash
go run ./cmd
```

После запуска API будет доступно по адресу:

```text
http://localhost:8080
```

## Основные маршруты API

| Метод | Маршрут | Описание |
| ------ | ------- | -------- |
| POST | `/register` | Регистрация пользователя |
| POST | `/login` | Авторизация пользователя |
| GET | `/vacancies` | Получить список вакансий |
| GET | `/vacancy?id={id}` | Получить вакансию по ID |
| POST | `/vacancies` | Создать вакансию |
| PUT | `/vacancies?id={id}` | Обновить вакансию |
| DELETE | `/vacancies?id={id}` | Удалить вакансию |
| GET | `/resumes` | Получить список резюме |
| POST | `/resumes` | Создать резюме |
| PUT | `/resumes?id={id}` | Обновить резюме |
| DELETE | `/resumes?id={id}` | Удалить резюме |
| GET | `/responses` | Получить список откликов |
| POST | `/responses` | Создать отклик |
| GET | `/favorites` | Получить список избранного |
| POST | `/favorites` | Добавить вакансию в избранное |
| DELETE | `/favorites?id={id}` | Удалить вакансию из избранного |
| PUT | `/users/role` | Изменить роль пользователя (только admin) |

---

## Аутентификация

Для защищённых маршрутов необходимо передавать JWT-токен в заголовке:

```text
Authorization: Bearer <your_jwt_token>
```

## Формат ответов API

### Успешное выполнение операции

```json
{
  "message": "Operation completed successfully"
}
```

### Получение списка данных

```json
{
  "message": "Data retrieved successfully",
  "data": [
    ...
  ]
}
```

```json
{
  "message": "No data found",
  "data": []
}
```

### Ошибка

```json
{
  "error": "Error description"
}
```

## Права доступа

### Admin

- Просмотр всех вакансий
- Просмотр всех резюме
- Просмотр всех откликов
- Редактирование любых вакансий
- Удаление любых вакансий
- Редактирование любых резюме
- Удаление любых резюме
- Изменение ролей пользователей

### Employer

- Создание вакансий
- Редактирование своих вакансий
- Удаление своих вакансий
- Просмотр откликов только на свои вакансии

### Applicant

- Создание резюме
- Редактирование своих резюме
- Удаление своих резюме
- Создание откликов
- Добавление вакансий в избранное
- Просмотр своего избранного
